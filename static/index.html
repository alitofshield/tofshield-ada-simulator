How to interpret these decisions

Good for dev: passes the structural and core numeric checks used here for ingestion, visualization and replay. Conditional: resolve the listed data-layout, timing or instrument-domain issue. No good as supplied: empty measurements or an HDF5 read failure; see the file-specific reason. Empty files can still serve as schema fixtures.

ML training: mixture and drug standards provide useful label sources, but observation-level labels, exposure windows, matching controls and independent run partitions need curation. Ambient mipTOF observations are not verified target-class examples. Derivatives of one run must stay in the same partition.

Evidence: all datasets inventoried; full numeric scans of the core spectra, peaks and timing arrays, mass-axis checks and SHA-256 fingerprints. Auxiliary waveforms and experimental detection performance are not exhaustively validated. Source paths and local-versus-downloaded provenance are recorded per file.

Companions reviewed: Vocus experimental PDF; four MATLAB analysis files; mipTOF experiment notes, air-flow calibration workbook and processed CSV metadata. These describe noise/threshold issues, concentration uncertainty, contamination and acquisition events that limit scientific reuse.
