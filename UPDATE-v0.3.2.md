# Dark Theme Restoration — v0.3.2

Version 0.3.2 restores the original dark analytical color system requested for the viewer. It retains all v0.3.1 structural improvements:

- enlarged **Local Analytical Workspace** title;
- exactly two primary workspaces;
- full-width Instrument Configuration interface;
- definitions, defaults, allowed ranges and model-status labels for every parameter;
- responsive desktop and mobile layouts;
- read-only handling of source HDF5 files.

The configuration remains an educational model and does not represent manufacturer performance specifications.
