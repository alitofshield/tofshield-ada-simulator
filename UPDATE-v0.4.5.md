# TOFshield Simulator - Instrument Configurator v0.4.5

- Calculates detached graph width and height directly from the browser window instead of reusing the original embedded canvas dimensions.
- Recalculates graph dimensions when the detached window is resized.
- Labels the EIT axes as acquisition time and integrated ion signal.
- Labels the mass-spectrum axes as mass-to-charge ratio and stored signal intensity.
- Adds cursor-following crosshairs and axis spike labels.
- Curve hover displays both horizontal and vertical values.
